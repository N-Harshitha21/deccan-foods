# Deccan Foods

A responsive Deccan Foods storefront MVP for browsing biscuits, breads, and mints, building a cart, placing mock orders, and reviewing order history across five South Indian states.

## Run locally

pnpm install
pnpm --filter @workspace/deccan-foods run dev

The current build uses mock catalogue, cart, checkout, and order data. The data layer is structured for a future Shopify Storefront API integration.
